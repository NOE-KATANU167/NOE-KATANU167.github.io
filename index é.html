SecDash

Tableau de bord de sécurité · projet personnel

Le problème

Les tentatives répétées de connexion sont le premier signe d’une attaque par force brute, mais elles passent inaperçues quand personne ne lit les journaux.

Ce que fait SecDash

Il collecte les événements de connexion, repère les adresses IP qui échouent trop souvent, crée des alertes classées par gravité et permet à un administrateur de les traiter ou de bloquer une IP. Une API protégée par clé reçoit les journaux d’autres machines.

Mesures de sécurité

Mots de passe hachés, requêtes préparées, jetons CSRF, session régénérée à la connexion, verrouillage après 5 échecs, expiration après inactivité, en-têtes de sécurité et compte de base de données aux droits limités.

Code source sur GitHub

Technologies
PHP 8, MySQL, Apache (XAMPP), Chart.js, VS Code
Règle de détection
5 échecs en 10 minutes depuis la même IP déclenchent une alerte.
Limites connues
Pas encore de HTTPS, de double authentification ni de limitation de débit sur l’API. Ce sont les prochaines étapes.
